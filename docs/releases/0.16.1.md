# Corrección de instalación 0.16.1

La CI de 0.16.0 detectó un fallo real en Windows: Python nativo bajo Git Bash
intentaba leer el catálogo UTF-8 con la página de códigos del sistema. Se
corrigen las lecturas de catálogo, manifiestos y archivos de proyecto usadas
por la instalación y auditoría de skills, y la escritura del manifiesto.

La regresión reproduce CP1252: falla antes del cambio con UnicodeDecodeError y
pasa después. `commands-behavior.test.py`: 15 pruebas correctas; coherencia de
versión: 11/11; paridad de scripts y skills: 11/11; actualización de una base
histórica: correcta. La migración 059 solo actualiza la versión del esquema.

La instalación global y los proyectos betterhealth y gestor3.0 informan
`ready: true`, versión 0.16.1 y ningún archivo requerido ausente o modificado
respecto de su inventario de runtime. Implementación: `b5d0b9b` en `main`.

Se conserva la evidencia y las limitaciones documentadas en `0.16.0.md`.
La corrección se publica como patch separado, sin reescribir el tag 0.16.0.
Rollback: revertir este commit restaura las lecturas dependientes de la
codificación del sistema; no se eliminan datos ni tablas.
