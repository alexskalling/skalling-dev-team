# Skalling 0.19.0 — 2026-11-06

Disponible desde el checkout local. Esta actualización no publica tag ni Release.

## Cambios

El caso real de reordenamiento del menú en Actas terminó en 2m18s, con una entrega
y una revisión sin rechazos. Sin embargo, Teo cargó TDD/Ponytail y construyó un test
temporal para una edición declarativa; Alex arrastraba unos 260k tokens de entrada
reportados en una llamada. Esta versión atiende esas dos fuentes de trabajo extra.

- Copy, iconos y orden estático local y reversible usan lectura, edición e inspección
  focal del resultado. No requieren cargar TDD/Ponytail ni fabricar un RED/GREEN.
  La excepción no aplica a lógica, permisos, rutas, contratos, datos persistidos o accesibilidad.
  `strict_tdd` sigue activo para comportamiento y bugs funcionales.
- Las dos skills tienen contratos breves y guías extensas bajo demanda. Teo,
  contrato compartido, constitución y plantilla de proyecto coinciden.
- El plugin de eficiencia observa el historial antes de una llamada. A partir de
  64k tokens **estimados** y ocho mensajes solicita `session.compact` nativo.
  No recorta mensajes ni edita la base de OpenCode. La cola del runtime decide el
  punto seguro; la llamada actual todavía puede llevar el historial grande.
- Sólo solicita una vez hasta observar que el historial bajó de la mitad del umbral.
  Si falla, no bloquea ni reintenta en bucle. Sin API informa la limitación.
- El resumen debe conservar objetivo, restricciones, autorizaciones humanas,
  workflow, hallazgos y siguiente paso. Tras compactar, el agente recupera el estado
  de TeamDB, sin borrar historia ni crear otro workflow.
- `metadata.skalling_context` en resultados de `skalling_workflow` separa tamaño
  aproximado de historial/sistema/herramientas, preparaciones de contexto y llamadas de herramientas desde carga del plugin
  y estado de compactación. La estimación usa bytes UTF-8 serializados / 4:
  no es tokenización del proveedor, facturación ni atribución exacta por workflow.

## Configuración y compatibilidad

Usa la API pública de OpenCode 2; capacidad comprobada en 2.2.5. `contextTokens`
(opción del plugin, entero >=16000, defecto 64000) cambia el umbral aproximado;
`autoCompact:false` desactiva esta optimización. No cambia modelos ni límites del
proveedor. El guard puede solicitar compactación aunque `compaction.auto` nativo
esté desactivado: para desactivar este guard usar su opción `autoCompact`.

La compactación consume una llamada de resumen, puede incluir validación del
runtime y es imperfecta: no se promete ahorro neto ni tiempo fijo sin medición
real. Un sistema/herramientas grande por sí solo no dispara compactaciones inútiles.
No se recorta un primer mensaje grande del usuario. Estado en memoria acotado a
64 sesiones; una recarga reinicia los contadores. Sesiones de agentes ajenos a
Skalling conservan su comportamiento.

## Instalación, validación y rollback

Migración 068 sólo actualiza `schema_meta.version`. Instaladores global/local
incluyen el nuevo módulo; manifiestos lo exigen y preservan modelos personalizados.
La actualización de skills clasifica el contenido antes de agregar referencias:
una skill administrada no se confunde con una personalización por los archivos nuevos.
Las sesiones abiertas pueden conservar instrucciones anteriores; el próximo
arranque carga el bundle nuevo. No hace falta reiniciar workflows.

Pruebas: deduplicación, reactivación tras reducción, API ausente/fallida, desactivación,
aislamiento por agente y sesión, paquete instalado, contratos, versión y migración.
El smoke `tests/runtime/context-budget-smoke.py` usa OpenCode instalado y proveedor
local simulado: comprueba una solicitud nativa, resumen, reducción de payload y
conservación del identificador de tarea. No mide razonamiento ni calidad de un LLM.

Rollback por unidad: desactivar `autoCompact` retira la optimización sin tocar
memoria; reinstalar 0.18.0 retira el módulo y las reglas nuevas. Conservar backups
del instalador y no revertir registros de workflows ni bases para deshacer prompts.

Referencias de API: [plugins de servidor](https://dev.opencode.ai/v2/docs/build/plugins/server)
y [compactación](https://dev.opencode.ai/v2/docs/compaction).
